# Domain docs

Cozi uses one shared glossary and one ADR directory.

- Read the root `GLOSSARY.md` and the relevant decisions in `docs/adr/` before exploring a domain area.
- Use the glossary's terms in issues, specs, refactors, and tests. Record important terms with the domain-modeling skill when the team agrees on their meaning.
- Call out any conflict with an existing ADR and explain why the decision may need to be revisited.
- Proceed when relevant docs are absent. Add glossary entries or ADRs when the underlying term or decision is resolved.
