# Triage labels

Use the GitHub label from this table when a skill refers to a canonical triage role.

| Role              | GitHub label      | Meaning                                       |
| ----------------- | ----------------- | --------------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer needs to evaluate the issue      |
| `needs-info`      | `needs-info`      | More information is needed from the reporter  |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | A person needs to implement it                |
| `wontfix`         | `wontfix`         | The team won’t pursue the issue               |
